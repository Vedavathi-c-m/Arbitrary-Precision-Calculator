# Arbitrary Precision Calculator (APC)

## 📌 Project Overview
The Arbitrary Precision Calculator (APC) is a C-based application designed to perform arithmetic operations on extremely large integers that exceed the limits of standard C data types such as `int` or `long`.

To overcome this limitation, each digit of the number is stored in a node of a **Doubly Linked List**, allowing the program to handle numbers of virtually unlimited length.

The calculator processes numbers digit by digit, similar to manual arithmetic operations, and supports operations like addition, subtraction, multiplication, and division.

---

## 🚀 Features
- Performs arithmetic on very large integers
- Supports **Addition, Subtraction, Multiplication, and Division**
- Uses **Doubly Linked List** to dynamically store digits
- Handles carry and borrow operations efficiently
- Modular C program structure
- Command-line based interface

---

## 🛠 Tech Stack
- **Language:** C Programming

## 🔄 Program Flow
User Input → Store digits in Doubly Linked List → Perform Arithmetic Operation → Manage Carry/Borrow → Display Result
